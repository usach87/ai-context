# Example: Monorepo

```text
/
├── AGENTS.md
├── apps/
│   ├── web/
│   └── mobile/
├── services/
│   ├── auth/
│   ├── billing/
│   └── notifications/
├── packages/
│   ├── database/
│   └── contracts/
├── infrastructure/
└── docs/
```

The root file is a map. Local instructions exist only where a domain has meaningful additional constraints. Billing work should not require mobile UI conventions in permanent context.
